## About The Project

Built for the CS2 project in the course Fundamentals of Computing || under Dr. Amr Elmougy

Our team has created a fun project revolving around the popular game Geometry Dash using C++ and Qt Creator.
We have created 5 levels and as you go up the levels you will face increased difficulty and more obstacles. We also made sure to make each level unique with different backgrounds
and sound effects. Also, we added an item shop, so as you collect coins while playing you may purchases a different skin for your player.
